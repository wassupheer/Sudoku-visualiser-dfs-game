# Sudoku Solver with Visualization (DSA Project)

This project is a Python-based Sudoku game and solver that uses  
**Depth First Search (DFS) with Backtracking** along with a Tkinter GUI.

Users can either solve the Sudoku manually or watch the algorithm
solve it step by step using visualization.

---

## Features
- Interactive 9×9 Sudoku grid
- Manual puzzle solving
- DFS backtracking solver
- Step-by-step visualization
- Solution validation

---

## Algorithm Used
- Depth First Search (DFS)
- Backtracking
- Constraint checking (row, column, 3×3 grid)

---

## Tech Stack
- Python 3
- Tkinter (GUI)
